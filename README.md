# Motivational Quotes CLI

<!-- repo-intro:start -->
**Project snapshot:** A small Python command-line exercise for generating random motivational quotes, accepting user-added quotes, and optionally saving results to a text file.

**What it demonstrates:** Python · CLI input/output · random sampling · file persistence.
<!-- repo-intro:end -->

## What this project demonstrates

- Functions and basic program structure
- Interactive command-line input
- Working with Python lists and `random.sample`
- Writing generated output to a file

## Run

```bash
python quotes.py
```

This is intentionally kept as an early learning project in the portfolio.
